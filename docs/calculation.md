# Источники и ограничения

- [ЦБ РФ: официальные курсы](https://www.cbr.ru/currency_base/daily/).
- [Калькулятор TKS](https://www.tks.ru/auto/calc/) — использовался для сверки контрольного сценария; API не подключён.
- [ЕТТ, группа 87](https://www.alta.ru/ett/gruppa87.html) — классификация и примечание 6.
- Официальные ссылки BMW на каждую версию находятся в `public/catalog.json`.
- Источники таблиц платежей перечислены в `public/rates.json`.

Ставки ограничены 2026 годом. Полная независимая сверка всех комбинаций с TKS не завершена. Различайте модификацию, рынок и год спецификации; год карточки не заменяет месяц/год производства конкретного автомобиля.

Для автоматического заполнения признака ЕТТ ещё требуется документальная проверка клиренса и остальных характеристик каждой комплектации. До проверки пользователь вводит клиренс и подтверждает остальные критерии. Код учитывает бензиновую схему, объём строго выше 2800 см³ и возраст менее трёх лет; для больших объёмов действуют собственные тарифные ветви.

Дата расчёта текущая. Для нового ввода месяца и года принято 15-е число; это допущение сохраняется в отчёте. Старые отчёты не пересчитываются. На границе возрастной категории следует проверить фактическую дату по документам.
