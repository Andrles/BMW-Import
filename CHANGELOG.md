# Изменения

## 0.5.0 — 25.09.2026

- Компактная панель: одна кнопка «Поделиться», PDF/печать в меню и закрытие крестиком.
- «Поделиться» в предложении для клиента, включая отчёты из истории.
- Предпросмотр полной PNG-карточки: автомобиль, платежи, итог, курсы и примечания.
- Telegram, WhatsApp, MAX и Email через системные службы macOS. Список зависит от установленных расширений; при отсутствии нужного сервиса — сохранение PNG и ручное вложение.
- Суммы берутся из сохранённого отчёта без пересчёта по новым курсам.
- Сохранение PNG через диалог macOS; печать и PDF остаются доступны.
- 25 автоматических тестов, включая контрольный расчёт со скриншота TKS и сохранность данных при экспорте.

Незавершённое: №004 — документальная проверка конкретных комплектаций SUV. Автоматическое подтверждение ЕТТ по одному названию модели не включено.

## 0.4.1

- Светлый интерфейс «Быстрый расчёт» с итогом справа.
- Месяц и год выпуска; убран отдельный раздел точного дня и даты расчёта.
- Пустые расходы автоматически становятся нулём.
- X6 LCI 30i: 258 л.с.; 40i: 381 л.с. Старые версии выделены отдельно.
- Новая иконка BMW Import.
- Тип автомобиля, привод, клиренс и проверка условий ЕТТ.
- 22 автоматических теста.

Открытая задача: проверенные данные ЕТТ для конкретных комплектаций каталога.
